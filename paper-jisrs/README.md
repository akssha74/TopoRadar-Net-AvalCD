# JISRS manuscript source

Target: *Journal of the Indian Society of Remote Sensing*  
Article type: Research Article  
Review model: double blind

## Build

```bash
tectonic -X compile main.tex
tectonic -X compile supplementary_information.tex
```

`main.tex` uses the official December 2024 Springer Nature `sn-jnl.cls` and `sn-apacite.bst` files. The anonymous Word main document is generated by `submission-jisrs/format_jisrs_docx.py`.

## Compliance

```bash
python3 ../submission-jisrs/check_compliance.py
```

The script enforces the 4,000-word Research Article limit, 200-word abstract limit, keyword/highlight counts, highlight character limits, heading depth, and required data/declaration/AI sections.

The full pre-retarget manuscript remains in `../paper/`; this directory is the separate JISRS-formatted submission variant.
