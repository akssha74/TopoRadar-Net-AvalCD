\section*{Highlights}
\begin{itemize}[leftmargin=1.5em,itemsep=0.1em,topsep=0.2em]
\item The model is tested across four mountain systems and seven avalanche events.
\item Three training runs show parity with strong alternatives and a gain only over simple differencing.
\item Terrain inputs help in some regions but do not improve accuracy uniformly.
\item The slope prior penalizes some pixels that contain genuine avalanche debris.
\item The road-corridor test succeeds in the Pamirs but misses the only corridor avalanche in northern Norway.
\end{itemize}
